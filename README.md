## Features

- **RAM Optimizer** — Free up memory with one click, see exactly how much was released
- **CPU Monitor** — Real-time CPU usage with detailed analytics
- **Disk Monitor** — Track disk usage and health
- **Process Manager** — View and kill running processes
- **Startup Manager** — Control which apps launch on boot
- **Temp File Cleaner** — Remove junk files to free disk space
- **DNS Flush** — Clear DNS cache instantly
- **Clipboard Cleaner** — Wipe clipboard contents
- **Turbo Engine** — Game mode, high performance, freeze background apps
- **Auto Clean** — Schedule automatic RAM optimization by threshold
- **Mini Widget** — Floating always-on-top overlay for quick stats
- **Battery Monitor** — Live battery status with charging indicator
- **Network Monitor** — Real-time download speed
- **Uptime Tracker** — See how long your system has been running
- **Dynamic Accent Color** — UI color changes red when RAM is critical
- **Sound Alerts** — Audio feedback for critical RAM usage
- **Multi-language** — Multiple language support
- **Customizable Appearance** — Change accent color, dynamic colors, sounds

## Installation

1. Download `ramos-installer.exe` from [Releases](../../releases)
2. Run the installer

> ⚠️ **Windows may show a security warning** because this app is new and not yet widely distributed.
> Click **"More info" → "Run anyway"** to proceed. This is normal for new open-source apps.

Download `ramos.exe` directly from [Releases](../../releases) and run it — no installation needed.
